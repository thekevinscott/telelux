# Web component

`<telelux-transcript>` renders an agent transcript in the browser.

## Install

```sh
pnpm add telelux-element
```

```html
<script type="module">
  import 'telelux-element';
</script>

<telelux-transcript></telelux-transcript>
```

See it running on the [demo](./demo) page.
