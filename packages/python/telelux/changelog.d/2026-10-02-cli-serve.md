**Added** The `telelux` command. `telelux [TRANSCRIPT]` serves the viewer through Uvicorn and opens it in a browser; `--no-browser` suppresses the browser, and `--host` / `--port` are forwarded to Uvicorn. Unusable transcripts exit `1` with the reason on stderr, and usage errors exit `2` (#15).
**Added** `click` is now a runtime dependency (it was already installed with Uvicorn).
