**Added** `parseRawTranscript` parses a Claude Code session JSONL file into docent's transcript shape in the browser, sniffing the format or taking it through the `format` option, and returns a `ParseResult` instead of throwing. It ships Lit-free at the `telelux-element/parse` subpath and from the main entry, with `ParseResult`, `Format`, and `ParseRawOptions` exported as types. (#4)
