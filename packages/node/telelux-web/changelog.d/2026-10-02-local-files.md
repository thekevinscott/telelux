**Added** — The viewer opens a local transcript file chosen with **Open a transcript file** or dropped on the page, turning it into a compressed `#v=1&data=` link when the link fits in 8,000 characters. A larger file keeps the current transcript on screen, explains the limit, and offers **Download standalone HTML**: a copy of the viewer with the file baked into a new `<script type="application/x-ndjson" id="transcript">` slot, which the page renders when it has no fragment.
